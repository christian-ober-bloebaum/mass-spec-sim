# Eine Methode planen

Kopiere diese Vorlage für eine neue Aufgabe in deine Notizen. Ein paar klare
Sätze reichen. Besprich den Plan vor einer schwierigeren Umsetzung kurz mit dem
Betreuer. Die Vorlage ist eine Denkhilfe, keine zusätzliche Programmieraufgabe.

## 1. Ziel

Was soll die Methode bewirken? Beschreibe es in einem Satz ohne C#-Syntax.

## 2. Eingaben und Ergebnis

Welche Werte bekommt die Methode? Was liefert sie zurück? Welche Daten darf sie
ändern und welche sollen unverändert bleiben?

## 3. Kleines Beispiel

Wähle so wenige Werte, dass du das Ergebnis von Hand bestimmen kannst.

| Eingabe | Erwartetes Ergebnis | Warum? |
| --- | --- | --- |
| Ein normaler Fall | … | … |
| Ein Randfall | … | … |

## 4. Ablauf in Worten

Schreibe einzelne Schritte auf. Wenn du „für alle Werte“ schreibst, brauchst du
wahrscheinlich eine Schleife. Wenn ein Schritt von einer Bedingung abhängt,
beschreibe beide Fälle. Wenn du einen bisherigen Bestwert brauchst, benenne ihn.

## 5. Umsetzung und Prüfung

Setze zunächst nur einen Schritt um. Welche Variable zeigt dir im Debugger, dass
er funktioniert? Prüfe anschließend die vorher notierten Beispiele.

## 6. Rückblick

Was hat anders funktioniert als erwartet? Welchen Fehler hast du gefunden und
wie könntest du ihn beim nächsten Mal früher erkennen?
